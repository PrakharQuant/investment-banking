# Investment Banking — A Career Guide

A single-page GitHub Pages site explaining investment banking as a career: industry structure, product groups (Coverage vs Products), a 56-term filterable terminology decoder (M&A, valuation, financing, ECM/DCM, restructuring), key skills with weightings, bank tiers and league tables, compensation bands, the Analyst→MD career path, exit opportunities (PE, HF, corp dev, MBA) and how to break in.

Created by [Prakhar Gupta](https://www.linkedin.com/in/prakhar-gupta-5b7250372/) · X: [@PrakharQuant](https://x.com/PrakharQuant) · bestofprakhar@gmail.com

## Live site
https://prakharquant.github.io/investment-banking/
